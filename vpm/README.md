## Add to Creator Companion

Use:

`vcc://vpm/addRepo?url=https%3A%2F%2Fsorakaito0.github.io%2Fverdant-media%2Findex.json`

or open VCC > Settings > Packages > Add Repository and paste the repository URL.

## Update model

VCC owns files inside the Verdant package. Your Unity scene and world-specific content remain in the project. Do not put manually positioned cats, supporter props, lighting or personal world assets inside the package.

VRCLinking, AudioLink and ProTV are optional integrations and are installed separately.
