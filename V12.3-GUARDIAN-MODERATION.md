# Verdant V12.3.0 — Guardian Moderation

This GitHub folder is designed to be merged into the existing `verdant-media` repository.

## Backgrounds fix

`config/backgrounds.json` now works with the V12.3 runtime format. Entries can use:

- `id` — stable background key
- `name` — display name
- `requiredTier` — 0 free, 1 Basic, 2 Supporter, 3 VIP, 4 Elite, 5 Guardian
- `path` — file path relative to `baseUrl`
- `thumbnailPath` — lightweight menu preview relative to `baseUrl`

The Unity menu shows its black/template card first. Once the GitHub thumbnail downloads, it replaces that card automatically. If a thumbnail is missing or GitHub is offline, the template stays visible instead of a broken image.

## Adding a new background

1. Put the full image under `assets/backgrounds/` in the correct tier folder.
2. Add an entry to `config/backgrounds.json`.
3. Add a small thumbnail under `assets/backgrounds/thumbnails/` and set `thumbnailPath`.
4. Commit/push to GitHub Pages.
5. In Verdant, use Refresh GitHub Backgrounds or reopen the world.

No Unity UI rebuild is required just to add another GitHub background, provided the total stays within the current remote capacity of 40 entries.
