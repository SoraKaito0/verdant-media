# Verdant Network

**Verdant World System — v15.4.12**  
Public release record: 29 October 2026

Verdant is a VRChat world interface and community system. The Main Board, tablet and supporting modules bring together media controls, world utilities, personalisation, supporter recognition and staff-facing tools.

## System features

- **Main Board & Tablet:** Central menus for world controls, settings and navigation.
- **Media:** Shared video controls, radio, galleries and music visualisation.
- **World utilities:** Navigation, timers, mirrors and configurable interaction modules.
- **Supporters:** Tier recognition, badges, membership displays and supporter benefits.
- **Community:** Announcements, posters, galleries and other remote content.
- **World management:** Staff utilities, role configuration and moderation integration.

## Remote content structure

| Path | Purpose |
| --- | --- |
| `config/` | World configuration, available modules, staff roles, supporter settings and world lists |
| `announcements/` | Announcement text, manifests and archived messages |
| `ads/` | Community poster images and display configuration |
| `badges/` | Supporter badge metadata and icon artwork |
| `supporters/` | Supporter display data and membership perk definitions |
| `gallery/` | Photo gallery manifests and images |
| `media/` | Featured media, thumbnails and radio metadata |
| `themes/` | UI theme metadata and preview artwork |
| `updates/` | System release metadata, status and change history |
| `backdrops/`, `banners/`, `posters/` | Supporting world and community artwork |
